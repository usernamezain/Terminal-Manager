# Write Good First Issue Skill

Use this skill to author well-structured, welcoming issues marked with `good first issue` and `help wanted`.

## Structure of a Good First Issue

1. **Context & Motivation**:
   - Explain what the feature/fix does from a user perspective.
2. **Where in Code to Look**:
   - Provide direct links to relevant files, e.g., `src/renderer/features/...` or `src/main/...`.
3. **Suggested Implementation Steps**:
   - List step-by-step guidance on how to implement the change without overwhelming the contributor.
4. **How to Test**:
   - Provide exact test commands to run (`npx vitest run ...`).
5. **Contributing Guide Reference**:
   - Link to `HOW-TO-CONTRIBUTE.md` for branch naming, git clone, and PR workflow.

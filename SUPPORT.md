# Support & Getting Help

Welcome to the Terminal Manager community! Here are the best ways to get help, ask questions, and troubleshoot problems.

---

## 1. Documentation & Knowledge Base

Before opening an issue or discussion, check our offline and online documentation:
- **In-App Documentation Browser**: Press `F1` or click the Docs icon in the sidebar for offline searchable guides covering shortcuts, themes, shell integration, and profiles.
- **Repository Guides**: Browse [`docs/content/`](docs/content/) for comprehensive topics.
- **Settings Reference**: See [`docs/content/_generated/14-settings-reference.md`](docs/content/_generated/14-settings-reference.md).

---

## 2. GitHub Discussions

For general questions, architecture discussions, prompt ideas, or sharing custom themes:
- Join the conversation on **[GitHub Discussions](https://github.com/mughaldev0/Terminal-Manager/discussions)**.
- **Categories**:
  - 💡 **Ideas**: Share new feature suggestions and gather community feedback.
  - 🙏 **Q&A**: Ask how to configure shells, ConPTY, or custom themes.
  - 💬 **General**: Community discussions and workflow tips.

---

## 3. GitHub Issues

Use **[GitHub Issues](https://github.com/mughaldev0/Terminal-Manager/issues)** strictly for reproducible bugs, documentation corrections, and verified performance regressions.

### Generating a Redacted Diagnostic Report
When opening a bug report, attach a diagnostic report generated directly from Terminal Manager:
1. Open **Settings (`Ctrl+,`)** > **Help & Support** (or click **Report an Issue**).
2. Click **Copy Diagnostics**.
3. All sensitive paths and keys (`%USERPROFILE%`, `%USERNAME%`, `[REDACTED_SECRET]`) are stripped automatically.
4. Paste the report into your issue.

---
